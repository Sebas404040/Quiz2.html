# Proyecto Quiz2

## Descripción
Este proyecto es una aplicación web diseñado para un reto de clase con estilos CSS y con estructura en HTML5.
Basado en los requerimientos entregados por el trainer, diseñamos este aplicativo.

## Características
- **Interfaz amigable**: Diseño intuitivo y fácil de usar.
- **Resultados inmediatos**: Muestra la estructura señalada por el trainer y cumple con los requerimientos señalados.
- **Compatibilidad**: Funciona en navegadores modernos.
## Instalación
1. Clona este repositorio:
    ```bash
    git clone https://github.com/usuario/quiz2.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd quiz2
    ```
3. Abre el archivo `Quiz2.html` en tu navegador.

## Uso
1. Abre la aplicación en tu navegador.
2. Selecciona un cuestionario.
3. Responde las preguntas y revisa tus resultados.

## Tecnologías utilizadas
- **HTML5**
- **CSS3**
